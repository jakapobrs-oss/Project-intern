# บทที่ 5
# สรุปผลและข้อเสนอแนะ

> ร่างเนื้อหาภาษาไทย · ฐาน: `internship-book-materials.md` §12

## 5.1 สรุปผลการดำเนินงาน

โครงงานนี้ได้พัฒนาระบบจัดการจอประชาสัมพันธ์ดิจิทัล (Digital Signage Management System) จนสามารถใช้งานได้ครบวงจร ตั้งแต่การจัดการเนื้อหา การจัดผังการแสดงผล การกำหนดตารางเวลา การควบคุมจอโทรทัศน์และจอ LED ระยะไกล ไปจนถึงการประกาศเหตุฉุกเฉินและการเฝ้าระวังสถานะอุปกรณ์ ระบบทำงานบนสถาปัตยกรรม 6 ส่วนในรูปแบบคอนเทนเนอร์ มีส่วนจัดการสำหรับผู้ดูแล (Admin UI) และส่วนแสดงผล (Player) ทั้งบนเว็บและ Android ที่พร้อมใช้งานจริง โดยบรรลุวัตถุประสงค์ทั้งหมดที่ตั้งไว้ในบทที่ 1

ในด้านคุณภาพ ระบบมีกรณีทดสอบอัตโนมัติประมาณ 133 กรณี ครอบคลุมส่วนสำคัญของระบบ และมีระบบ CI ตรวจสอบความถูกต้องและความปลอดภัยทุกครั้งที่แก้ไขโค้ด

## 5.2 ปัญหาที่พบและแนวทางแก้ไข

| ปัญหาที่พบ | แนวทางแก้ไข |
|---|---|
| เครือข่ายภายในอาจขัดข้องชั่วคราว ทำให้จอหยุดแสดงผล | ออกแบบให้ player ดึง manifest แล้ว cache เนื้อหาไว้ เล่นต่อได้แบบ offline-friendly |
| ทีวีมีหลายยี่ห้อ คำสั่งควบคุมต่างกัน | ออกแบบชั้นควบคุมแบบ enum protocol รองรับหลายยี่ห้อผ่าน HDMI-CEC และ RS-232 |
| ความเสี่ยงด้านความปลอดภัยจากไฟล์อัปโหลดและ URL ภายนอก | เพิ่มการสแกนไวรัสด้วย ClamAV และการป้องกัน SSRF ในการตรวจสอบ URL |
| ต้องควบคุมสิทธิ์การเข้าถึงและตรวจสอบย้อนหลังได้ | ใช้ระบบ RBAC 7 บทบาท ร่วมกับกระบวนการอนุมัติและการบันทึก audit log |

## 5.3 ข้อเสนอแนะและการพัฒนาต่อยอด

แนวทางการพัฒนาต่อยอดในอนาคต (Phase 7) ได้แก่
1. รองรับ HDMI-CEC แบบ native บนอุปกรณ์แสดงผลให้สมบูรณ์ยิ่งขึ้น
2. เสริมความปลอดภัยของการยืนยันตัวตนด้วย httpOnly cookie
3. รองรับหลายภาษา (i18n) ในส่วนจัดการ
4. ขยายระบบ CI/CD ให้ครอบคลุมการ deploy อัตโนมัติ
5. เพิ่มตารางข้อมูลแบบ time-series สำหรับ telemetry เพื่อวิเคราะห์แนวโน้มของอุปกรณ์
