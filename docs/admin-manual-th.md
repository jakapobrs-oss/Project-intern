# 📖 คู่มือผู้ใช้งาน Admin (ภาษาไทย)

> สำหรับเจ้าหน้าที่ที่ใช้งานระบบจัดการจอประชาสัมพันธ์
> ไม่ต้องมีความรู้ด้านเทคนิค

---

## เข้าสู่ระบบ

1. เปิดเบราว์เซอร์ไปที่ URL ของระบบ (เช่น `https://signage.your-org.example`)
2. กรอก **username + password** ที่ได้รับ
3. กรอกผิด 5 ครั้ง บัญชีจะถูกล็อก 15 นาที (ความปลอดภัย)

### บทบาท (Role) และสิทธิ์
| Role | ทำอะไรได้ |
|---|---|
| **super_admin** | ทุกอย่าง + จัดการผู้ใช้ |
| **admin** | ทุกอย่างยกเว้นจัดการผู้ใช้ |
| **editor** | อัปโหลด content, สร้าง playlist/schedule (รออนุมัติ) |
| **approver** | อนุมัติ/ปฏิเสธ content + schedule |
| **operator** | สั่ง emergency + ควบคุม TV/LED |
| **viewer** | ดูอย่างเดียว + ดูรายงาน |

---

## งานที่ทำบ่อย

### 1. อัปโหลดสื่อ (Content)
หน้า **Contents** → ปุ่ม Upload
- รองรับ: รูป (JPG/PNG/WebP/GIF ≤20MB), วิดีโอ (MP4/WebM ≤500MB)
- หรือใส่ **URL** (เว็บ/สตรีม)
- หลังอัปโหลด ระบบสร้าง **thumbnail** ให้อัตโนมัติ
- กด **Submit** เพื่อส่งให้ผู้อนุมัติ

### 2. อนุมัติสื่อ (สำหรับ approver)
หน้า **Contents** → รายการที่สถานะ *pending* → **Approve** หรือ **Reject** (พร้อมเหตุผล)
> เฉพาะ content ที่ *approved* แล้วเท่านั้นที่นำไปจัดตารางได้

### 3. สร้างหน้าจอ (Presentation)
หน้า **Presentations** → เลือก layout (เต็มจอ / แบ่งโซน / มี ticker) → ลาก content ลงแต่ละโซน

### 4. สร้าง Playlist (Plan)
หน้า **Plans** → เพิ่ม presentation เรียงลำดับ (ลากสลับได้) → ตั้งเวลาแสดงต่อหน้า

### 5. ตั้งตารางออกอากาศ (Schedule)
หน้า **Schedules** → New
- เลือก **Plan** + **กลุ่มจอ (Player Group)**
- ตั้งช่วงวันที่ (เริ่ม–สิ้นสุด)
- ตั้ง **ช่วงเวลาในวัน** (เช่น 08:00–17:00) และ **วันที่เล่นซ้ำ** (เช่น จันทร์–ศุกร์)
- **priority** เลขมาก = สำคัญกว่า (ใช้แก้กรณีตารางชนกัน)
- editor บันทึก = *รออนุมัติ* / admin บันทึก = *active* ทันที

> ⚠️ ถ้าตารางชนกัน (กลุ่มเดียวกัน เวลาทับ priority เท่ากัน) ระบบจะเตือน — ปรับ priority หรือเวลาให้ไม่ทับ

### 6. ประกาศฉุกเฉิน (Emergency Broadcast)
หน้า **Emergency** → New → พิมพ์ข้อความ/รูป/URL → เลือกเป้าหมาย (ทุกจอ / กลุ่ม / จอเจาะจง)
- override ทุกจอทันที (เช่น แจ้งเตือนไฟไหม้)
- ตั้งเวลาหมดอายุได้ — ระบบยกเลิกเองอัตโนมัติ
- กด **Cancel** เพื่อยกเลิกก่อนกำหนด

### 7. ควบคุม TV / LED
หน้า **TV Control**
- เลือกจอ → สั่ง เปิด/ปิด, เปลี่ยน input, ปรับเสียง
- จอ LED: ส่งข้อความ (เลือกสี/เอฟเฟกต์/ความเร็ว)

### 8. ดูรายงาน (Reports)
หน้า **Reports** — uptime จอ, content เล่นบ่อยสุด, สรุป audit
- ดาวน์โหลดเป็น **Excel** หรือ **PDF** ส่งผู้บริหารได้

### 9. ดูสถานะระบบ (Dashboard)
หน้าแรก — จำนวนจอ online/offline, content รออนุมัติ, schedule ที่ active

## เคล็ดลับ
- จอแสดง offline แต่ภาพยังเล่น = เน็ตจอมีปัญหา แต่จอเล่นจาก cache ได้ (ไม่ต้องตกใจ)
- เปลี่ยน content แล้วจอยังไม่เปลี่ยน — รอ 1–2 นาที (จอเช็คทุก 60 วิ)
- ปัญหาที่พบบ่อย ดู [troubleshooting.md](troubleshooting.md)

> สลับภาษา ไทย/อังกฤษ + โหมดมืด ได้ที่แถบบนขวา
